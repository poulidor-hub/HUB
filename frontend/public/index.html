Gestion des utilisateurs
Ajouter un utilisateur
  1. Administration → Utilisateurs → Ajouter
  2. Saisir identifiant, mot de passe, email
  3. Choisir un rôle : Admin, Manager, User, Viewer
  4. Optionnel : assigner à une ou plusieurs applications

Opérations en masse : Importer CSV (⋮ → Importer depuis CSV) ou Assigner des rôles (sélection multiple → ⋮).

Profils d'accès

Un profil est un modèle de rôles applicable en un clic. Administration → Utilisateurs → Profils → Nouveau profil.

Supprimer / désactiver

Table des utilisateurs → crayon → Désactiver. L'utilisateur ne peut plus se connecter mais ses données sont conservées.

Gestion des applications
Ajouter une application
  1. Déployer l'app sur le serveur (voir guide d'installation)
  2. L'app s'auto-enregistre → apparaît En attente dans Admin → Applications
  3. Approuver : bouton ✓ pour passer en Actif
Pool de ports

Le Hub alloue automatiquement les ports des nouvelles apps. Voir l'état : Administration → Pool de ports.

Plages : API 9000-9499, Frontend 4200-4699. Configurable dans .env.

Sauvegardes
Sauvegarde planifiée

Administration → Sauvegardes → configurer par app : mode scheduled, cron (ex : 0 2 * * *), rétention.

Restaurer

Administration → Sauvegardes → ↺ sur l'app. ⚠️ clear_existing=true efface toutes les données.

Snapshot système

Sauvegarde la configuration du Hub (apps, comptes, utilisateurs). Administration → Sauvegardes → Snapshots.

Audit et monitoring

Le tableau de bord Audit & Suivi offre :

  • Vue d'ensemble : KPIs, alertes, sessions actives
  • Par application : stats, top utilisateurs
  • Logs détaillés : recherche par action, app, utilisateur, IP
  • Erreurs : 401, 403, 500 avec filtres

Rétention configurable : AUDIT_RETENTION_DAYS=90, ERROR_RETENTION_DAYS=30.

Messagerie interne

Messages → Nouveau : cible (tous ou spécifiques), priorité (Info/Warning/Urgent), expiration.

Les messages apparaissent dans le Hub (🔔) et dans chaque application.

VPN WireGuard

Administration → VPN : activer, renseigner clé privée/publique, adresse, endpoint. Cliquer Déployer.

Commandes utiles (terminal)
# État des services
docker compose ps

# Logs en direct
docker compose logs -f hub-api

# Redémarrer après modification du .env
docker compose down && docker compose up -d

# Mise à jour
git pull && docker compose up -d --build

# Sauvegarde manuelle de la DB
docker compose exec db pg_dump -U hubadmin hub_auth > backup.sql

  • ✅ SECRETS_ENCRYPTION_KEY définie
  • ✅ ALLOWED_ORIGINS restreint aux domaines connus
  • ✅ APP_WHITELIST_NETWORKS limité
  • ✅ ACCESS_TOKEN_EXPIRE_MINUTES=30
  • ✅ .env non versionné (pas dans Git)
  • ✅ Ports non exposés sur Internet
